# @apophis-sdk/solana
Solana ecosystem support for the Apophis SDK. Apophis is a strongly opinionated SDK for building web3 applications in different ecosystems.

## Installation
Install with your favorite package manager's equivalent of:

```bash
npm install @apophis-sdk/core @apophis-sdk/solana
```
